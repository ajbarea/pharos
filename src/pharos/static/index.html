Shortcut gate

The gate asks whether plant membership is predictable from shape alone, reading no words. It is expected to score above chance, because ground truth is defined by content. What matters is that the baseline is measured and significant against its own permutation null.

A gate run takes seconds, so it waits for this button.

Analyst review

A proposal is two assertions: a verdict, and the label it would be released under. Each reviewer differs from the by-the-book one on exactly one axis. A compartment shortfall is a ruling somebody is entitled to make, so the reviewer escalates; a level or capacity objection is nobody's to lift, and the release is withheld.

Reviewers are decision procedures with named parameters, not simulated people. Each row bounds a mechanism and estimates nothing about how a human analyst behaves.

    Run a model

    One triage task from the corpus, answered by a model you choose. The governed label of the answer is the join over every source report the task read.

    Running a model needs the local Pharos server.This copy of the explorer is a frozen bundle with no backend, so it cannot call a model. Install Pharos and start the explorer locally:

    uv sync --group ui
uv run python -m pharos.cli serve

    Then open http://127.0.0.1:8080. The model view lists the models you have pulled with Ollama.
